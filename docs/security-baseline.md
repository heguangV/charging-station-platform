# NCS 安全基线

## 1. 身份与权限

- 用户、管理员、决策查看者和 ML 任务令牌用途隔离；服务端从会话取得主体 ID，不接受客户端冒充。
- 密码优先使用 Argon2id；默认演示密码仅在开发种子启用，正式配置首次登录必须修改。
- 会话数量、期限、退出撤销和敏感操作重新认证按 SRS `NFR-S-04` 及接口契约执行。
- 管理操作在 Controller 和应用服务两层校验角色，前端隐藏按钮不构成授权。

## 2. 传输与配置

- 正式环境只允许 HTTPS/WSS；证书私钥权限最小化，不存入仓库、数据库或普通日志。
- `.env` 仅用于开发。生产凭据由部署环境或秘密管理系统注入，输出配置时只允许安全摘要。
- 监听地址默认回环；对 VM 网络开放前必须确认防火墙、NAT 和访问来源。

## 3. 数据与输入

- SQLite 仅由同机 `ncs_server` 访问；文件、备份和恢复目录使用服务账号最小权限。
- SQL 全部参数化，排序、过滤、分页和枚举使用白名单；不得接受 SQL 片段。
- 金额、电量、时间、坐标、分页和上传文件在协议与应用边界重复校验。
- 头像按真实格式识别、限制大小/尺寸、重新编码并剥离元数据；只保存服务端生成的相对路径。

## 4. 日志与隐私

- 应用日志包含 UTC 时间、级别、模块和请求 ID；不得记录 Authorization、Token、密码、验证码、完整手机号、钱包余额、SQL、堆栈或私钥。
- 对外错误返回稳定错误码和安全短诊断，不返回内部路径与数据库信息。
- 应用日志保留 30 天，审计/运维日志保留 180 天；注销后的业务记录按 SRS 匿名化与保留。

## 5. 安全验证门禁

- 鉴权缺失、越权、冻结账号、令牌撤销、会话上限和重新认证均有契约测试。
- 幂等键冲突、重放、并发分配、结算恢复、迁移失败和备份恢复均有自动化测试。
- 依赖版本与许可证定期复核；发布前检查提交中不存在凭据、个人数据和运行产物。
- 安全问题按 `SECURITY.md` 私密报告；高危问题修复前不公开可利用细节。
