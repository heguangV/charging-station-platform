# 用户端与运营大屏浅色界面重构

日期：2026-09-06。范围：UC-U 用户端呈现、UC-W-01/03 和 NFR-U-01/02；业务接口与统计口径不变。

## 改动

- Qt 用户端保留 420×760，统一自然绿、浅绿白底和暖黄色提示。原生 QPainter 绘制充电场景，登录和首页使用相同视觉语言。
- 站点名称、地址、可用数量和价格分层排列；电桩卡片边框限定到卡片本身，避免 QLabel 继承边框。充电页的导航和取消预约并排，禁用结算按钮明确变灰。
- 大屏移除固定 1920×1080 画布变换，桌面三列、窄屏重排并滚动；卡片标题与图表分开分配高度。ResizeObserver 监听图表容器变化。
- ECharts 坐标、图例、tooltip 与数据系列同步浅色配色；预测图留出图例和轴标题空间，高峰用小圆点表示，完整日期与预警保留在 tooltip。

- Qt 使用独立临时截图驱动和 offscreen 平台渲染实际窗口，检查登录、首页、站点详情、预约充电、账户和订单。截图驱动使用 Mock 服务，不替代真实 REST 全流程验收。

## 环境与边界

本次复用现有 build-ncs：Qt 6.8.3、CMake 3.22.1；未修改工具链基线。这不构成 Qt 6.2 / CMake 3.24+ 跨版本验收。

设备快慢充数量统计仍缺后端契约，保留“暂无设备类型统计”；没有虚构数据。现有需求矩阵的业务完成状态不提高。测试截图数据为合成夹具。

源代码保留为当前分支的未提交修改；现有外部旧目录启动的用户端和 Vite 进程未重启。大屏产物在 apps/dashboard/dist，Qt 产物在 build-ncs/apps/user/ncs_user。

## 第二轮材质与交互调整

按用户后续偏好增加 Apple 风格的轻盈层次与极简科技感：Web 顶栏和卡片使用 backdrop-filter、半透明白色、柔和色晕和细边高光；卡片悬浮、按钮按压和短入场动画均不改变布局。prefers-reduced-motion 会关闭 CSS 动效，不支持背景模糊的浏览器回退浅色底。

Qt 使用 QSS 半透明渐变模拟磨砂材质（不是实时背景模糊），底部导航增加低强度阴影与 180ms 选中颜色过渡。设置 NCS_REDUCE_MOTION 可关闭导航过渡。未对文字本身施加模糊。

第二轮验证：用户端构建、ncs_user_smoke、check.sh、git diff --check 通过；大屏生产构建和全部 10 项浏览器回归通过。重新渲染并复核手机端与大屏截图。

## 第三轮：按用户提供的充电 App 参考图重构

本轮取代前两轮材质方案：以白色/浅灰为底，深色大标题、深蓝主按钮、橙色价格和绿色可用状态为主；移除主要内容区的透明模糊和光晕。Qt 登录页重排为品牌、欢迎标题、手机号/验证码和主按钮；首页重排为附近标题、地图搜索、场景横幅、位置选择和价格优先的站点卡片。

场景图为本次 imagegen 生成，保存在 apps/user/resources/charging-scene.png 和 apps/dashboard/src/assets/charging-scene.png，分别通过 Qt Resource 和 Vite 打包。图像按比例裁切，所有标题、价格和按钮均由原生控件/HTML 实时渲染，未烘焙到图片。没有引入参考 App 的品牌、虚构优惠券或尚不存在的业务入口。

验证：ncs_user 构建、4 项 ncs_user_ CTest、check.sh 和 git diff --check 通过；大屏类型检查/生产构建与 10 项浏览器测试通过。Qt 以 QT_SCALE_FACTOR=2 在实际 420×760 逻辑窗口生成 840×1520 截图，并复核登录、首页、充电等页面。大屏复核非空数据 1366×768 与 1920×1080，其他响应式尺寸由原有浏览器测试覆盖。

Qt 截图采用现有 Mock 服务；其中距离来自现有演示数据，不能作为真实定位验收证据。未改动线上账户、数据与旧目录运行的进程，未提交 Git。
