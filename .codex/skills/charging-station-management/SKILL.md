## 最终技术目标

- 当前车主用户端使用 Linux Qt Widgets + C++，验收窗口固定 420×760；Android/QML 是远期目标，不属于当前验收。
- Linux PC 管理端使用 Qt Widgets + Qt Charts，并承载 `QTcpServer`；不增加第三个独立服务进程。
- 桌面 C++ 最低兼容 Qt 6.5.3 和 Qt Creator 6.2+，当前使用 Qt 6.8.3 验证；保持 Windows 10/11 MSVC 2019/2022 与 Ubuntu 22.04+ GCC 11+ 可编译性。
- `ncs_admin`/`ncs_user` 使用 `QTcpServer`/`QTcpSocket` 提供带长度前缀的 JSON Socket 协议，并使用 Qt 并发设施避免阻塞事件线程。
- SQLite 3 单文件 `charge_platform.db` 是当前唯一主数据库，由同机两个 Qt 程序通过公共数据/服务层访问；大屏不得直接写文件。
- Vue 3 + ECharts 提供运营大屏；Python/scikit-learn RandomForest 提供预测。
- Ubuntu 22.04+ 用于开发与验收；`ncs_user`、`ncs_admin` 和 SQLite 严格验收时在同一 VM 运行，VM 保持 NAT。
- 腾讯地图为主地图服务；本地地图页 JS Key 与 PC 服务器端 WebService Key 分离，并保留预置坐标、Haversine 和浏览器导航降级。

## 等价增强不变量

- Qt Widgets 用户端必须覆盖 SRS 全部 `UC-U` 页面、异常流和固定 420×760 竖屏交互。
- `ncs_user` 与 `ncs_admin` 必须使用公共数据库模块访问同一 SQLite 文件，并保留自动初始化、种子数据、外键、WAL、事务、恢复与统计结果。
- 大屏使用管理端或 Python 每 30 秒原子导出的版本化 `dashboard.json`，不直接打开 SQLite。
- SQLite 中金额用整数分、时间用 UTC ISO 8601 文本；界面仍按元、两位小数和本地时间展示。
- 密码使用专用密码哈希；`admin/123456` 和界面展示的模拟验证码只允许开发配置。
- 只为真实业务引入并发：SQLite 每线程使用独立连接并由专用 `QThread` 工作对象访问，CPU 密集或批处理任务使用 `QThreadPool`，Socket 使用 Qt 异步事件，ML 使用 `QProcess`；不得建立无业务功能的线程演示程序，也不得让后台线程直接操作 UI。

## 核心产品规则

- 三类角色为车主用户、运营管理员和决策查看者；运营管理员可管理并查看大屏，决策查看者只读访问大屏，权限由公共业务服务层与 PC 服务器端校验。
- 注册需要唯一用户名、必填唯一手机号和密码；支持用户名/手机号密码登录。开发配置另提供模拟验证码自动注册。
- 恢复昵称、头像、手机号脱敏和余额 0 的 SRS 用户资料规则。
- 北京五个固定 NCS 演示站点共 48 台设备：18 台 120kW 直流、10 台 60kW 直流和 20 台 7kW 交流，使用 GB/T 接口并预置 6 台故障设备和 90 天历史数据；界面默认展示近 30 天。
- 种子固定为 `20260901`，生成 300 个模拟车主、约 9,000 个订单和 900 条充值记录，保持已确认的站点、时段、快慢充与状态分布，并补齐 ML 零订单小时。
- 容量目标为 3,000 注册账号、100 个同时在线 Socket 连接、50 同时排队、48 同时充电以及 20 请求/秒、50 请求/秒短时峰值；使用独立 SQLite 测试文件和 Python 异步 TCP 虚拟用户验证。
- 有空闲设备时直接预约并保存价格快照；无空闲设备时按“站点 + 快充/慢充类型”即时排队，入队仅显示预估价，轮到后锁定 5 分钟最终报价，确认后创建 15 分钟预约。
- 排队、报价确认和预约阶段可幂等取消并立即释放/递补，不收费不处罚但保存原因；充电开始后只能结束并结算。
- 仅运营管理员可二次确认、填写原因并选择目标设备状态后强制释放待确认或已预约设备；用户流程取消、不自动重新排队但通知提供入口。充电中设备不得直接强制释放，但须保留 SRS 的紧急远程重启能力：先停止计费并幂等结算或生成待处理结算，再通知、审计和重启。
- 活动流程状态固定为 `10/QUEUED`、`20/QUOTE_PENDING`、`30/RESERVED`、`40/CHARGING`、`50/SETTLING`、`60/COMPLETED`、`70/CANCELLED`、`80/SETTLEMENT_FAILED`、`90/EXPIRED`，原因另存。
- 一个用户最多一个活动充电流程，一个设备最多一个活动占用；分配与状态转换由公共服务层在 SQLite 事务中控制。
- 充电默认倍率 60、范围 1～300；PC 服务器端持续计费并在 Socket 重连后恢复。
- 北京按行政区基础定价，站点通过腾讯 `adcode` 归区并保留自定义区域扩展；排队压力每 5 分钟按 0/10%/20%/30% 阶梯调服务费，ML 建议为 ±20% 且由管理员批准 1/6/24 小时，二者相加后限制为基础服务费的 80%～140%，活动流程保存价格快照，所有调价可审计。
- 五区种子基础总价依次为海淀 1.35、朝阳 1.45、丰台 1.25、石景山 1.15、通州 1.05 元/度；全市最低起充金额固定为 5.00 元。
- 用户可手动或按目标金额/余额上限结束；正常流程避免欠费，少量超额记录欠费。
- 欠费用户可登录、查看和充值，但不能发起新充电流程；充值在同一事务中优先清偿欠费，清零后按账号状态自动恢复权限。
- 结算、余额扣减、钱包流水、设备释放和统计更新在同一事务中幂等完成。
- 管理端、大屏和 ML 的页面、指标、预测特征和异常行为按需求分析与 SRS 实现。

## 已冻结技术默认

- 任一 Qt 程序首次启动时在进程间初始化锁保护下创建 `charge_platform.db`、执行 schema 和种子；后续使用 `schema_version` 升级，开发与测试使用不同文件。
- 主键优先 `INTEGER PRIMARY KEY`，金额使用整数分、电量使用整数毫瓦时、时间使用 UTC ISO 8601 `TEXT`、状态使用 `INTEGER + CHECK`；两个进程分别使用数据库工作线程和独立连接，启用外键、WAL、`busy_timeout`，分配使用 `BEGIN IMMEDIATE`、条件更新与唯一索引，并发冲突最多重试 3 次。
- Socket 消息使用“4 字节网络序长度 + UTF-8 JSON”，包含协议版本、请求 ID、类型和时间；限制帧长，支持幂等键、错误码、拆包/粘包处理与重连快照。
- 普通用户会话最长 30 天并最多 3 个桌面终端，管理员最多 2 个终端；头像保存共享应用数据目录并重新编码，注销后按需求分析规定的期限清理或匿名保留。
- 大屏每 30 秒拉取管理端或 Python 原子导出的版本化 `dashboard.json`；快照 schema、指标口径和 Web 会话按需求分析实现。
- ML 天气/节假日/缺失值、零值 MAPE、基线降级、空闲桩/高峰公式以及任务超时与保留期按需求分析实现；模型必须在固定测试集上优于朴素基线才能通过 ML 子系统和完整产品验收，基线降级只用于运行时可用性，不能替代验收。
- 日志统一写入 `logs/ncs_YYYYMMDD.log`；应用日志保留 30 天、审计/运维日志 180 天。管理端通过 SQLite 在线备份或 `VACUUM INTO` 每日保留 7 份、每周 4 份，并可加密同步云服务器，RPO 24 小时、RTO 4 小时。
- 开发 VM 在校园网环境固定使用 VMware NAT；严格验收时两个 Qt 程序和 SQLite 同机运行。跨机器模式属于远期路线，绝不使用网络共享 SQLite 文件。

## 工程边界

- `apps/user`：固定 420×760 的 Linux Qt Widgets 用户端；若仓库暂未迁移目录，可复用现有 Widgets 目标。
- `apps/admin`：Linux Widgets PC 管理端，同时承载 TCP Socket、认证协同、调度、模拟计费和统计导出。
- `apps/dashboard`：Vue/ECharts 大屏。
- `core/domain`、`core/application`：领域模型、用例、状态机和接口。
- `infrastructure/sqlite`：schema、迁移、仓储、备份与事务。
- `infrastructure/map`、`files`：地图和文件服务。
- `ml`：数据准备、训练、预测、评估与模型版本。
- `tests`：领域、SQLite、Socket 协议、并发、恢复、UI 烟雾和端到端测试。
UI 不包含 SQL、权限、计费或余额扣减规则。网络、数据库、文件和 ML 任务不得阻塞 UI 或管理端事件线程。

## 安全与数据不变量

- 所有输入参数化查询；跨表操作使用事务、幂等键和审计日志。
- 故障、重启中、停用设备不可分配；待确认、已预约和待结算设备优先登记释放后自动重启，充电中设备仅允许按停止计费、幂等结算或待处理结算、通知、审计的受控流程紧急重启，空闲/故障设备可二次确认后立即重启。
- 价格和倍率保存会话快照；配置修改不影响历史和进行中会话。
- 订单、会话和钱包流水不物理删除；注销后匿名保留业务凭证。
- 令牌、验证码和密码只保存安全摘要；完整手机号、令牌、验证码和密钥不写日志。
- 地图、数据库备份和云服务密钥不进入源码、GitHub 或普通配置表；本地地图页读取受限 JS Key，WebService Key 仅由 PC 服务器端读取。
- 网络、地图、推送、数据库和 ML 失败必须有明确提示、重试或降级，不静默失败。
