# NCS 充电桩平台开发

## 文档路由

开始工作前阅读仓库根目录的 [README](../../../README.md)，了解实际目录、环境、构建和协作规范。

- 分析范围、架构、业务规则或研发顺序时，读取唯一的 [需求与研发指南](../../../docs/development-guide.md)。
- 实现或验收具体功能时，读取 [SRS](../../../docs/01-requirements-specification.md) 中对应的 `UC-*`、`BR-*` 和 `NFR-*`。
- 接入腾讯地图时，额外读取 [腾讯地图接入说明](../../../docs/tencent-map-setup.md)。

SRS 是最低验收基线，研发指南是唯一的执行口径。不要从历史对话、已删除的差异文档或远期实验代码推断当前需求。

## 实施原则

- 开始编码前确定对应需求编号、可观察结果、异常流和验证方法。
- 按研发指南的阶段顺序推进；优先建设 SQLite、领域状态机和事务一致性，再接入 UI、Socket、大屏与 ML。
- 需求不明确时不要降低 SRS；继续完成不依赖该细节的工作，并把必须由用户决定的事项明确提出。
- 技术替换只有在完整保留原行为并具备测试证据时才可采用。
- 文档描述目标，不能作为实现完成的证据。

## 工程不变量

- 当前交付为 Linux Qt Widgets 用户端、承载 `QTcpServer` 的 PC 管理端、同机共享 SQLite、Vue/ECharts 大屏和 RandomForest。
- Qt Widgets UI 不包含 SQL、权限、计费或钱包规则；公共领域和业务服务不得依赖 UI。
- 两个 Qt 进程使用独立 SQLite 连接、WAL、外键、事务和专用数据库工作线程。
- 网络、数据库、文件和 ML 任务不得阻塞 UI 或服务器事件循环；后台线程不得直接操作 UI。
- 金额使用整数分，电量使用整数毫瓦时，时间保存为 UTC ISO 8601 并在界面显示本地时间。
- 所有查询参数化，跨表写操作具备事务、幂等键和审计；完整手机号、密码、令牌、验证码和密钥不写日志。
- 真实 `.env`、数据库、日志、备份、构建产物和个人 IDE 配置不得提交。

## 验证与完成

- 修改后执行最小充分的构建、测试、烟雾测试和 `git diff --check`。
- 每项实现必须追踪到 SRS 编号，并覆盖正常流、异常流、权限和边界条件。
- 不以页面存在、演示成功或文档完成代替事务、并发、恢复、性能和安全验证。
- 只有 SRS 全部适用条目及验收清单均有通过证据时，项目才算完成。
